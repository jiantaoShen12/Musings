# Musings · 相交之后

A personal notebook about life trajectories, dynamical systems, virtual worlds, and the spaces between research and living. This project is deliberately separate from the academic CV site.

## Content and maintenance

- `index.html`: the first essay, article index, sources, metadata, and semantic markup.
- `styles.css`: typography, dark-forest palette, responsive layout.
- `script.js`: the interactive trajectory illustration, share button, and reading progress.

To add another essay, create a standalone `notes/<slug>.html` page, add it to the `文章目录` section of `index.html`, and place it in the main navigation or feature list. The site uses plain HTML/CSS/JS without a build system.

## Publish with GitHub Pages

This is a standalone repository, not part of the academic CV website.

1. Go to **Settings → Pages** for `jiantaoShen12/Musings`.
2. Set **Build and deployment → Source** to **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**, and save.
4. After Pages reports a successful deployment, open `https://jiantaoshen12.github.io/Musings/`.

Future commits to the same branch will publish updates automatically once GitHub Pages is enabled. Do not share the Pages URL as live until the deployment has succeeded.

The trajectory visualization is a conceptual illustration. It is not a biological reconstruction or model output. Text reflects the author's personal analogy, with limitations clearly distinguished from established biological findings.
